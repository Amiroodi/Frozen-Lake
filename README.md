Studied and reproduced an existing GitHub implementation of a Deep Q-Network (DQN) agent using PyTorch and Gymnasium to solve the FrozenLake environment.
(https://github.com/MehdiShahbazi/DQN-Frozenlake-Gymnasium)

Explored fundamental reinforcement learning concepts, including Q-learning, reward-driven learning, and sequential decision-making.
